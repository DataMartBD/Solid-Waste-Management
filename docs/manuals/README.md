# Smart Sweep — user manuals by user type

One short manual per kind of user. Each says what that user sees, a daily
routine, and step-by-step instructions for their own screens only.

| Manual | For | Lands on after sign-in |
|---|---|---|
| [City Corporation (City Viewer)](city-viewer.md) | City Corporation / Pourashova officers who oversee the service | City Dashboard |
| [Agency Admin](agency-admin.md) | The person running an agency (contractor, NGO, in-house team) | Daily Dashboard |
| [Supervisor](supervisor.md) | Ward supervisors who run routes, collectors and complaints | Daily Dashboard |

## Things every staff user should know

- **Sign in with your mobile number.** First time by SMS code; after that with a
  4-digit PIN (set it in *My Profile*). Office accounts may also use a password.
  Five wrong PINs lock the account for 15 minutes — sign in by SMS code to clear it.
- **The menu shows only the screens your role can open.** A missing screen is not a fault.
- **You only ever see your own area.** A collector sees their round, a supervisor
  their wards, an agency admin their agency, a City Viewer their city. The server
  enforces this; no filter can widen it.
- **Language and theme.** Switch Bangla / English and light / dark from the top bar.
  In Bangla, numbers are shown in Bangla digits.
- **Everything is per holding** (building): one charge, one bill, one daily visit,
  one QR tag per building, however many families live in it.
- **Every table exports** to Excel, CSV or PDF from its export buttons.
- **Sweep AI** (the floating assistant) answers "how many / which" questions from
  live data, limited to your area.

# স্মার্ট সুইপ — ব্যবহারকারীর ধরন অনুযায়ী ম্যানুয়াল

ব্যবহারকারী কী দেখেন, একটি দৈনিক রুটিন, এবং শুধু তাঁর নিজের স্ক্রিনের ধাপে ধাপে নির্দেশনা।

| ম্যানুয়াল | কার জন্য | লগইনের পর প্রথম স্ক্রিন |
|---|---|---|

## প্রত্যেক কর্মীর যা জানা দরকার

- **মোবাইল নম্বর দিয়ে লগইন করুন।** প্রথমবার SMS কোড দিয়ে; এরপর ৪ অঙ্কের পিন দিয়ে
  (*আমার প্রোফাইল*-এ সেট করুন)। অফিসের অ্যাকাউন্ট পাসওয়ার্ডও ব্যবহার করতে পারে।
  পরপর ৫ বার ভুল পিন দিলে অ্যাকাউন্ট ১৫ মিনিট বন্ধ থাকে — SMS কোড দিয়ে লগইন করলে খুলে যায়।
- **মেনুতে শুধু আপনার ভূমিকার স্ক্রিনগুলোই দেখায়।** কোনো স্ক্রিন না থাকলে তা ত্রুটি নয়।
- **আপনি শুধু নিজের এলাকাই দেখেন।** সংগ্রাহক নিজের রাউন্ড, সুপারভাইজার নিজের
  ওয়ার্ড, এজেন্সি অ্যাডমিন নিজের এজেন্সি, সিটি ভিউয়ার নিজের শহর। সার্ভার এটি নিশ্চিত করে;
  কোনো ফিল্টার দিয়ে তা বাড়ানো যায় না।
- **ভাষা ও থিম।** উপরের বার থেকে বাংলা / ইংরেজি এবং লাইট / ডার্ক বদলান।
  বাংলায় সংখ্যা বাংলা অঙ্কে দেখায়।
- **সবকিছু হোল্ডিং অনুযায়ী** (ভবন): প্রতিটি ভবনের একটি চার্জ, একটি বিল, প্রতিদিন
  একটি ভিজিট, একটি QR ট্যাগ — ভবনে যত পরিবারই থাকুক।
- **প্রতিটি টেবিল এক্সেল, CSV বা PDF-এ নামানো যায়।**
- **সুইপ এআই** (ভাসমান সহকারী) আপনার এলাকার লাইভ তথ্য থেকে "কতগুলো / কোনগুলো"
  ধরনের প্রশ্নের উত্তর দেয়।
